# Middle-earth Guide

An interactive guide to *The Silmarillion*, *The Hobbit* and *The Lord of the Rings*, with notes on the Jackson films and *The Rings of Power*.

Live at https://middle-earth-guide.vercel.app

The whole site is one self-contained file, `index.html`. Every push to `main` redeploys it on Vercel.

An unofficial, non-commercial fan guide. Not affiliated with the Tolkien Estate, Middle-earth Enterprises, New Line, Warner Bros. or Amazon.
